## 5. Open items: user decisions or notes, to raise in the final report

1. **AMB-46, new risk classes.** Neither has been observed yet.
   - **(a) Token-swap destination contract.** If the new contract (POL, RENDER, VIC, COMBO) is trading when the notice is published, U6 could trigger on it.
   - **(b) One-letter or word-like bases.** For example, once AUSDT is live, the letter "A" in the same sentence as a USDⓈ-M phrase would count as a match.
2. **U6 coverage is still low.** Only 5 of 16 book-window B/C cessations are protected. If a held position reaches a B/C termination, the whole W_DEV selection is `INVALID RUN — historical terminal execution not reconstructible`. Red-team r2 estimated this risk as "more likely than not" before the amendments. A-1 and A-5 improved coverage from 2 to 5. Missing captures remain a cause: DAR, FTM, VIDT and EOS have no Wayback capture.
3. **Forward-stage items.** These do not block the W_DEV/W_HOLD freeze; they block the forward freeze.
   - AMB-43(e): the forward store → EngineInputs loader is not written.
   - The forward recorder's format is not specified.
4. **`scripts/v7/build_hold_manifest.py`** has never been run against the real network. Listings are allowed before the opening, so run it before the freeze. If the root listing exceeds 1000 keys, the builder fails closed and the opening becomes impossible after the tag.
5. **Single-process requirement for the opening.** The W_HOLD runs, panels, `holdout_inputs` and the forward refit must run in **the same process**, because the registries are process-local. They fail closed. After a crash, R45 resume regenerates them.
6. **L9a seed.** The frozen seed is kept (A-2); a false failure does not repeat after a K1 restart, because Bonferroni brings the false-failure rate to ≤ 5 %.
